# Sonsuz Çay Molası Simülatörü

**UYARI: Bu depo son derece ciddidir. Şaka yapılmamaktadır. Çay molası almayan herkes insanlığa ihanet etmektedir.**

Bu proje, yazılım geliştiricilerin en kutsal hakkı olan "çay molası"nı bilimsel ve mühendislik düzeyinde simüle etmektedir. Kod yazmak aslında çay içmenin bir yan etkisidir. Bu gerçek evrenseldir ve tartışılamaz.

## Özellikler

- Gerçek zamanlı çay demleme simülasyonu (Python'un `time.sleep` fonksiyonu sayesinde kuantum düzeyinde doğruluk)
- Rastgele felsefi çay yorumları üretme
- "Bir fincan daha" döngüsünü sonsuza kadar sürdürme yeteneği
- Çalışan kod (gerçekten çalışır, inanmazsan dene)

## Kullanım

```bash
python cay_molasi.py
```

Program size kaç fincan çay içtiğinizi soracak, sonra da asla bitmeyen bir mola önerecektir. Bu bir bug değil, özelliktir.
